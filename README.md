# FinDesk downloads

Installers for **FinDesk**, Finyaara's Windows app that reads TallyPrime and keeps
[Finyaara](https://finyaara.com) up to date. Only the installers live here; the source is private.

**Download the latest:**
https://github.com/Finyaara/findesk-releases/releases/latest/download/FinDeskSetup.msi

- Windows 10 and 11 (64-bit), with TallyPrime on the same PC.
- FinDesk only reads Tally. It never creates, changes or deletes anything in your books.
- Sign in with your Finyaara account after installing. Help: hello@finyaara.com

Each release attaches one file named exactly `FinDeskSetup.msi`, so the link above always gets the newest.
